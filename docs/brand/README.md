# Brand assets — SST

The official logo is `sst-logo-original.webp` (symbol + "SST" wordmark, dark background). Every
other asset is a technical derivation of it, generated by
[`scripts/brand/build_brand_assets.py`](../../scripts/brand/build_brand_assets.py). There's no
redrawing, recolouring or added effects.

| Asset                                        | Content       | Format / size                | Used for                                        |
| -------------------------------------------- | ------------- | ---------------------------- | ----------------------------------------------- |
| `docs/brand/sst-logo-original.webp`          | Original      | WebP 1536×1024, ~72 KB       | Source of truth (never served)                  |
| `public/brand/sst-logo.webp`                 | Symbol + SST  | WebP 431×160, transparent    | Header from `sm` (640 px) up                    |
| `public/brand/sst-symbol.webp`               | Symbol        | WebP 174×160, transparent    | Header below `sm` (mobile)                      |
| `docs/brand/sst-logo.png` / `sst-symbol.png` | Logo / symbol | PNG 320 px tall, transparent | Masters for docs and future assets (not served) |
| `src/app/favicon.ico`                        | Symbol        | ICO 16/32/48, opaque         | Browser tab                                     |
| `src/app/icon.png`                           | Symbol        | PNG 192×192, opaque          | `<link rel="icon">`                             |
| `src/app/apple-icon.png`                     | Symbol        | PNG 180×180, opaque          | iOS home screen                                 |
| `src/app/(app)/opengraph-image.png`          | Logo + name   | PNG 1200×630                 | Social previews (Open Graph / Twitter)          |

**Rules**

- **Desktop and tablet:** symbol + SST. **Mobile, favicons and small spaces:** symbol only.
- **Transparent assets are for dark backgrounds:** the app uses them only on its dark theme.
  The black background was removed by un-compositing it, so light greys become partially
  transparent white. On light backgrounds, use the opaque icons or the original.
- **Don't** stretch, recolour, outline or add glow/shadow, and don't use the full logo on mobile
  headers.
- **Regenerating assets:**

  ```bash
  python3 -m pip install numpy scipy pillow
  python3 scripts/brand/build_brand_assets.py <dir with BarlowCondensed-Bold.ttf and Barlow-Medium.ttf>
  ```

  The fonts are Barlow / Barlow Condensed (OFL, Google Fonts) and are only needed for the Open
  Graph image.
